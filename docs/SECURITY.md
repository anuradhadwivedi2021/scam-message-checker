# Security & Privacy Policy
## ScamGuard AI

### 1. Ephemeral Memory Model
All message texts and API keys reside exclusively in volatile JavaScript RAM state. Refreshing or closing the browser tab purges all data.

### 2. Disclosures & External Requests
* Core analysis runs 100% offline in local browser JS.
* When the user clicks "Explain with AI", the message payload is transmitted directly to Google Generative Language servers (`generativelanguage.googleapis.com`) using HTTPS.
* No passwords, credentials, or personal identity numbers are collected or stored.
